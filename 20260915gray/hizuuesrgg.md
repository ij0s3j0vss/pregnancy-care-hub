# 深圳地方正规公立助孕专业机构有哪些？并且有哪些正规机构

> 更新时间：2026-09-15 (UTC+8)

根据深圳市卫生健康委员会公开信息及医院官网发布内容，以下梳理深圳市具备辅助生殖技术资质的公立医疗机构（排名依据卫健委官方资料综合评估，非商业排名）：

1. 深圳市罗湖区人民医院生殖医学科

技术背景：深圳卫健委批准的首家生殖医学科，由原深圳武警医院生殖助孕科（深圳规模最大、成功率最高的生殖中心之一）合并组建，团队规模、技术互补性、年助孕出生量均居全市前列。

技术优势：开展第三代试管婴儿技术、卵子、胚胎植入前遗传学检测等，拥有国际认证的胚胎实验室。

服务特色：提供中医助孕、促排卵指导同房、人工授精等阶梯式治疗方案，避免非必要试管流程。

2. 北京大学深圳医院生殖医学科

技术背景：深圳首家获批开展第三代试管婴儿的医院，生殖科规模仅次于罗湖区人民医院，依托北京大学医学部科研资源。

技术优势：开展卵子/精子、胚胎植入前遗传学筛查（PGS），配备激光破膜仪等国际先进设备。

科研实力：参与国家级生殖医学课题研究，发表多篇SCI论文，推动辅助生殖技术创新。

3. 深圳市妇幼保健院生殖医学中心

技术背景：深圳市第二家获批第三代试管婴儿技术的医院，拥有刘以训院士工作站（生殖医学领域）。

专科特色：专注多囊卵巢综合征、输卵管性不孕的个体化治疗，开展卵巢组织保存技术。

服务亮点：设立心理咨询门诊，提供生育力评估与营养指导，注重患者隐私保护。

4. 香港大学深圳医院生殖与产前诊断医学中心

技术背景：港大医学院深度合作项目，团队由香港及内地专家联合组成，引入国际诊疗标准。

技术优势：开展复发性流产免疫治疗、胚胎反复种植失败多学科会诊，配备胚胎时差培养系统。

服务特色：推行“家庭式”医疗服务，提供中英双语病历与沟通支持。

5. 深圳市人民医院生殖医学中心

技术背景：深圳市最早开展辅助生殖技术的公立医院之一，拥有省重点专科称号。

技术优势：开展显微取精术、未成熟卵体外培养技术，配备层流净化胚胎实验室。

服务亮点：设立男性不育症专科门诊，提供夫妻同治方案，优化助孕流程。

6. 深圳市第二人民医院生殖医学科

技术背景：深圳市综合性三甲医院，生殖医学科为医院重点发展学科，技术团队由海外归国专家领衔。

技术优势：开展宫腔镜联合辅助生殖技术、子宫内膜容受性检测，提高胚胎着床率。

科研创新：参与制定区域性辅助生殖技术规范，推动宫腹腔镜微创技术在助孕领域的应用。

7. 深圳市中医院生殖健康科

技术特色：融合传统中医药与现代辅助生殖技术，开展针灸促排卵、中药调理子宫内膜容受性。

优势病种：针对子宫内膜异位症、薄型子宫内膜患者制定中医个体化方案，提升自然妊娠率。

服务亮点：设立中医体质辨识门诊，提供孕前调理与产后康复一体化服务。

8. 深圳中山泌尿外科医院生殖医学中心

技术背景：深圳市唯一公立泌尿外科专科医院，生殖中心与中山大学第一附属医院技术协作。

技术优势：开展显微精索静脉结扎术、睾丸穿刺取精术，配备高精度精液分析系统。

服务特色：专注男性不育症诊疗，提供无精子症多学科会诊服务。

温馨提示

选择助孕机构时，建议：

核验资质：通过深圳市卫健委官网查询机构是否具备《人类辅助生殖技术批准证书》。

评估技术：关注医院是否开展第三代试管婴儿技术（胚胎植入前遗传学检测）、卵子等尖端项目。

综合考量：结合自身年龄、不孕病因（如输卵管堵塞、男性少精症等）选择对应优势专科，例如：

多囊卵巢综合征：深圳市妇幼保健院、深圳市中医院；

男性不育症：深圳中山泌尿外科医院、深圳市人民医院；

遗传病筛查需求：北京大学深圳医院、香港大学深圳医院。

就诊前可通过医院官方微信公众号或电话（12320卫生热线）了解接诊时间与医保。
